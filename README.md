# UnisoMapp
Mapa Interativo da UNISO
Descrição
O Mapa Interativo da UNISO é uma aplicação inovadora projetada para melhorar a experiência de navegação dentro do campus da Universidade de Sorocaba. Utilizando tecnologias de código aberto, nosso mapa oferece uma série de funcionalidades interativas para facilitar a localização e o deslocamento de visitantes e alunos.

Funcionalidades
Interações Dinâmicas: Explore o campus com facilidade, clicando em diferentes edifícios para obter descrições detalhadas das salas.
Criação de Rotas Personalizadas: Com a tecnologia de routing machine e openroute service, crie rotas a pé para chegar ao seu destino rapidamente.
Visualização de Eventos: Mantenha-se informado sobre os eventos da faculdade e saiba exatamente onde eles acontecerão no mapa.

Tecnologias Utilizadas:
OpenStreetMap: Para uma representação precisa e atualizada do campus.
Routing Machine/OpenRoute Service: Com uma chave API dedicada, navegue pelo mapa e trace rotas com facilidade.
Banco de Dados de Salas: Um banco de dados completo com todas as salas de aula e espaços físicos, incluindo identificadores únicos.

Próximos Passos
Estamos trabalhando para integrar o banco de dados da universidade, permitindo que os alunos identifiquem suas salas de aula designadas e sejam guiados até lá. A agenda do dia será sincronizada para oferecer uma experiência personalizada e eficiente.
